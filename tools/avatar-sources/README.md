# Свои картинки для аватарок-слотов

Положите сюда картинку с именем слота и запустите `node tools/build-avatars.mjs` — генератор
встроит её в `img/avatars/<слот>.svg`, кадрировав в круг под рамки-порталы. Пока картинки нет,
в слоте остаётся нарисованная генератором иллюстрация.

Слоты (формат — `.webp`, `.png` или `.jpg`; лучше квадрат от 512×512, лицо ближе к верхней трети):

- `pin-white-reaper` — «Белая жница»
- `pin-noir-gothic` — «Готика нуар»
- `pin-crimson-smile` — «Алая усмешка»
- `pin-moon-witch` — «Лунная ведьма»
- `pin-silver-vampire` — «Серебряная вампирша»
- `pin-raven-queen` — «Королева воронов»
- `pin-bloody-lace` — «Кровавое кружево»
- `pin-mono-angel` — «Монохромный ангел»

Кадрирование настраивается в `tools/build-avatars.mjs` (поля `focus` — точка лица, `zoom` — увеличение).
Используйте только изображения, которые вы вправе публиковать на сайте.
Папка `tools/` на Firebase Hosting не публикуется — на сайт попадают только готовые SVG.
